# ASP.NET Boilerplate

ASP.NET Boilerplate (ABP) is a general-purpose application framework for building modern web applications. It provides infrastructure and best practices for implementing Domain Driven Design (DDD) with a traditional N-Layer architecture.

## Core Purpose

- Application framework that automates common software development tasks
- Implements best practices for enterprise application development
- Provides modular and extensible architecture
- Supports both ASP.NET Core and legacy ASP.NET MVC 5.x

## Key Features

- **Modular Design**: Build and integrate custom modules
- **Multi-Tenancy**: Built-in SaaS application support from database to UI
- **Domain Driven Design**: Implements DDD principles and patterns
- **Module Zero**: Optional module providing user/role/permission management, tenant management, and organization units

## Status

End of support announced for May 2026. Continued support for ASP.NET Zero customers. Community encouraged to migrate to ABP Framework for long-term projects.

## Distribution

Distributed as NuGet packages with 30+ packages covering various integrations (Entity Framework, Dapper, Redis, SignalR, Hangfire, etc.)
